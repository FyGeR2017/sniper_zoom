# 🎯 Sniper Zoom v2.0 (Цифровой оптический прицел для игр)

Программа с графическим интерфейсом и работой из **системного трея Windows (без окон `cmd`)**, которая по нажатию кнопки делает аппаратное оптическое приближение поверх любых игр и окон.

---

## 📦 Установка (Setup) и Запуск

1. **Автономный установщик**: запустите [**`SniperZoom_Setup.exe`**](file:///c:/Users/x36/dev/sniper_zoom/SniperZoom_Setup.exe).
   - Установщик скопирует программу, создаст ярлыки с иконкой на **Рабочем столе** и в меню **«Пуск»**, настроит **автозапуск вместе с Windows** (в трее) и зарегистрирует приложение в системе.
2. **Портативный запуск**: запустите [`target\release\sniper_zoom.exe`](file:///c:/Users/x36/dev/sniper_zoom/target/release/sniper_zoom.exe) или [`start_zoom.bat`](file:///c:/Users/x36/dev/sniper_zoom/start_zoom.bat).

## 🔥 Главные возможности версии 2.0

### 1. 🔕 Работа в системном трее без пустого окна `cmd`
- Приложение скомпилировано как нативное графическое приложение Windows (`windows_subsystem = "windows"`) — **никаких черных окон консоли**.
- При нажатии на крестик `[X]` или кнопку **«🔽 В трей»** окно скрывается в системный трей возле часов.
- **ЛКМ по иконке в трее** — мгновенно показать / скрыть окно настроек.

### 2. ⚡ Настройки БЕЗ открытия приложения
Вы можете менять параметры прицела двумя способами, не открывая главное окно:
- **Контекстное меню в трее (ПКМ по иконке возле часов)**:
  - Быстрые игровые профили (`Штурмовик`, `Снайпер Mil-Dot`, `Панорама 16:9`, `Мега-прицел`).
  - Выбор кратности зума (`1.5x` – `10.0x`), размера зоны Scope (`300 px` – `1600 px`), формы линзы, прицельной сетки, цвета, рамки, режима (`Hold` / `Toggle`), слежения за курсором, паузы и автозапуска с Windows.
- **Горячие клавиши прямо в игре (с тактическим OSD-индикатором на линзе)**:
  - `[` и `]` — плавно уменьшить / увеличить кратность зума (`±0.25x`).
  - `-` и `=` — уменьшить / увеличить размер зоны Scope (`±60 px`).
  - `F9` — переключить прицельную сетку по кругу.
  - `F10` — переключить форму области (`Круг` → `Квадрат` → `Панорама 16:9` → `Полный экран`).
  - `F11` — переключить цвет прицела.

### 3. 📏 Увеличенная зона Scope и новые формы
- Максимальный размер зоны Scope увеличен с `650 px` до **`1600 px`**!
- **4 формы области прицела**:
  - ⭕ **Круглая линза (1:1)** — классическая оптика.
  - ⬜ **Скругленный квадрат (1:1)**.
  - 🖥️ **Широкая панорама (16:9)** — широкий обзор горизонта.
  - 📺 **Полный экран** — приближение на весь монитор.
- **Следование за курсором мыши (`Follow Mouse`)** и точная калибровка смещения центра по осям **X / Y** (`-300..+300 px`).

### 🎯 5. Управление прицелом и режим «Без приближения»
- **Отдельная кнопка включения/выключения прицела** (по умолчанию `F7`, переназначается в 1 клик на любую кнопку клавиатуры или мыши).
- **Режим «Выключать прицел при приближении»**: при беге и стрельбе от бедра виден наэкранный прицел, а при зажатии кнопки зума оверлейная сетка автоматически скрывается, оставляя чистое увеличение без помех для внутриигровой оптики винтовки!
- **Режимы**: `Удержание (Hold)`, `Переключение (Toggle)` и `Постоянно на экране (Always On)`.

### 4. 🎯 7 видов прицельных сеток и кастомизация оправы
- **Точка (Dot)**, **Крестик (Cross)**, **Снайперская сетка (Mil-Dot)**, **Тактический угольник (ПСО / ACOG `^`)**, **Т-Прицел (T-Cross)**, **Коллиматор (Круг с точкой)** и **Чистый зум без прицела**.
- Настройка толщины, центрального зазора (`gap`), длины лучей (`length`) и 4 стилей оправы линзы (`Тактическая`, `Неоновая`, `Тонкая 1px`, `Без рамки`).
